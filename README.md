# Maze Generator

This project is one I created upon receiving motivation from a friend. It is something that I chose to create for fun and to further my development abilities in Raylib. I first began developing the project at the beginning of my school year, around late August, however stopped development on it for some time. A second burst of motivation came when I learned about HackClub Terra and decided to use this project as my week 1 project. I have found this project incredibly fun to develop, having to find many clever solutions and optimizations in the code over the project lifespan. 

## Build and Install

To build the project, simply run make and run the produced executable.
If you download the build from GitHub, you can simply run it.
